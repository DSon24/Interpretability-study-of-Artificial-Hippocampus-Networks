# Dataset register — 8 Sep 2026

Gautam provided the four public resources below. This register records what each one may
be used for without silently changing the pre-registered experiment.

| Dataset | Source | Current role | Change control |
|---|---|---|---|
| **BABILong** | [booydar/babilong](https://github.com/booydar/babilong) | Best first optional construction-robustness pilot after the primary 3B RULER runs. | Scope the examples, metric, sample size, and stopping rule in a separate amendment before spending compute. |
| **NoLiMa** | [adobe-research/NoLiMa](https://github.com/adobe-research/NoLiMa) | Exploratory extension for non-literal or semantic-association retrieval. | Not part of the current confirmatory battery; promote only through a dated amendment. |
| **LongBench** | [THUDM/LongBench](https://github.com/THUDM/LongBench) | Existing RQ1 source. The current design uses the specified LongBench-E HotpotQA v1 path and n=60. | Do not silently switch dataset version, task, or cohort size. |
| **SCROLLS** | [tau-nlp/scrolls](https://github.com/tau-nlp/scrolls) | Related-work and future breadth candidate. | Not an immediate retention arm; adding it requires explicit scope and budget. |

## Standing rule

RULER NIAH n=60 remains the primary RQ2 cohort. These links are newly provided resources,
not newly authorized experimental cohorts. Results from any added dataset must be labelled
exploratory unless a pre-run amendment defines its role, metric, sample size, and decision
rule.

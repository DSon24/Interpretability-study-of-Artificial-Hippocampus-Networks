# Personal-Interest Experiments

This folder collects researcher-initiated experiments that I pursued from personal scientific interest beyond the core confirmatory analysis. They are retained as exploratory or supporting evidence and should not be presented as preregistered primary results unless another project document explicitly assigns that role.

Included experiment groups:
- Corrected LV-Eval FactRecall validation
- BABILong construction-robustness study
- Long-context RULER retention extension
- RULER answer-prefix ablation
- Corrected candidate-conditioned C2 analysis
- Mixed-distribution J-Lens transfer

Original result artifacts remain in their existing locations; this folder is a convenience collection for review and paper drafting.
